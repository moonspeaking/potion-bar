# Призрачный Бар — браузерный порт

Играть: https://moonspeaking.github.io/potion-bar/ (устанавливается как PWA, работает офлайн).

Порт Potion Bar на чистый JavaScript без сборки и npm: `index.html`, `js/`, `assets/`.

## Локальный запуск

```bash
python3 tools/serve.py        # http://localhost:8765
```

## Структура

- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` — PWA-оболочка;
- `js/` — код игры; `assets/` — ресурсы;
- `tools/` — сервер и вспомогательные скрипты;
- `research/` — результаты реверса оригинала (Ghidra, SWF), не публикуется (в `.gitignore`).

## Магазин улучшений
Как в оригинале (Windows-версия), в начале 3-го, 5-го и 7-го уровня каждого эпизода открывается магазин: три предложения
по весам уровня, цены от накопленного кошелька, одна покупка за визит. Содержимое бара (горелки, амулеты, украшения, специи,
особые стаканы) определяется покупками (`js/shop.js`). Правила выбора предложений и цен восстановлены из `game.exe`;
эффекты денежного / неперекипающего стакана и самовара в exe найти не удалось — они сделаны по описаниям из игры
(денежный +50% к оплате, неперекипающий и самовар не портят зелье, самовар греется сам и собирает заказ клиента).
